# Volta SNAP extensions

Code in this directory is **Volta SNAP-specific** and is not intended for pull requests to [canmet-energy/h2k-hpxml](https://github.com/canmet-energy/h2k-hpxml).

## Layout

- `snap/` — Volta SNAP platform integration (API clients, orchestration, deployment helpers)
- `local/` — gitignored local workspace (test H2K files, one-off scripts)

Shared translation improvements belong in `src/h2k_hpxml/` so they can be contributed upstream.
